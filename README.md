# Harshit Keshari (Harshit107) — Premium 3D Developer Website

An award-winning Awwwards-tier developer portfolio featuring genuine Three.js 3D depth, fluid Framer Motion choreography, and obsidian glassmorphism.

Built as a modern standalone project inside `Portfolio Groups/portfolio-3d`, completely preserving all career history, projects, skills, education, and credentials while replacing the legacy CRA setup with high-performance React 19 + TypeScript + Vite.

## ✨ Features & Visual Highlights

- **Genuine 3D Technical Sculpture**: Lightweight, 60fps Three.js geometric wireframe (Icosahedron + glowing Torus Knot core + orbiting particle cloud) with cursor-reactive parallax and dynamic lighting.
- **Obsidian Glassmorphism Aesthetic**: Deep near-black background (`#0A0D14`), ambient translucent glass panels (`backdrop-filter: blur(16px)`), subtle borders, and atmospheric radial light orbs.
- **Interactive 3D Card Tilt & Glare**: Cards respond dynamically to cursor movement with 3D perspective rotation and specular glare overlays.
- **Dynamic Accent Themes**: Switch between 5 curated cyberpunk accent palettes in real-time:
  - 🟢 **Emerald Matrix** (`#10B981`)
  - 🔵 **Cyber Cyan** (`#06B6D4`)
  - 🟣 **Electric Violet** (`#8B5CF6`)
  - 🟡 **Sunset Amber** (`#F59E0B`)
  - 🔴 **Neon Crimson** (`#F43F5E`)
- **Dark / Light Mode**: Smooth theme transition with localStorage persistence.
- **Mobile-First Responsiveness**: 100% fluid layouts across mobile, tablet, laptop, and ultrawide monitors (no under-construction blockers).
- **Interactive Micro-Interactions**: Confetti celebration upon copying email/phone or sending messages, typing role animator, and magnetic buttons.
- **100% Preserved Content**:
  - **About**: Cornerstone OnDemand module ownership, 3+ years experience stats, personal bio.
  - **Experience**: Cornerstone OnDemand, Hexagon Manufacturing Intelligence, MTX Group, Teknesya Networks.
  - **Projects**: Digital Classroom, App Store Android, Expensify, Freely-Email (NPM), UEM Connect, OneLogin.
  - **Skills**: Core Languages, Frontend Architecture, Backend & APIs, Databases, DevOps & Tooling, Familiar With.
  - **Education**: UEM Jaipur (B.Tech CSE, 8.3 CGPA) & Kendriya Vidyalaya Andal (76%).
  - **Contact**: Direct email copy, secondary email, phone number, location, and social links.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite + TypeScript
- **Styling**: Styled-Components + CSS Variables
- **3D Graphics**: Three.js
- **Animations**: Framer Motion
- **Icons**: Lucide React + custom SVG vector paths
- **Effects**: Canvas Confetti

## 🚀 Running Locally

```bash
# Navigate to the project directory
cd "portfolio-3d"

# Install dependencies (if not already installed)
npm install

# Start development server
npm run dev

# Run production build
npm run build

# Preview production build
npm run preview
```
